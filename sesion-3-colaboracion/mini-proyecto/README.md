# Mini-proyecto: glosario de Git

[glosario.md](glosario.md) es el archivo con el que empieza el repo de cada equipo. No lo edites aquí: trabajas en el repo de tu equipo, al que te invitan al inicio de la sesión.

El glosario tiene tres secciones. Cada integrante del equipo se queda con una y solo agrega términos en la suya:

| Integrante | Sección         |
|------------|-----------------|
| 1          | Guardar cambios |
| 2          | Ramas           |
| 3          | GitHub          |

Si tu equipo es de dos, usen las dos primeras.
