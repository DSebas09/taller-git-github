# Cheatsheet de Git

## Básicos
```bash
git init
git status
git add <archivo>
git commit -m "mensaje"
git log --oneline --graph
git diff
```

## Remotos
```bash
git clone <url>
git push
git pull
```

## Ramas
```bash
git switch -c <rama>
git merge <rama>
```

## Deshacer
```bash
git restore <archivo>
git revert <commit>
git reflog
```
