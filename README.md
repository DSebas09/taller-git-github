# Taller de Git y GitHub

Taller práctico de control de versiones para proyectos académicos y de desarrollo. Empezamos desde cero: no necesitas haber usado Git antes.

Al terminar sabrás guardar el historial de tu trabajo, subirlo a GitHub y colaborar con otras personas en un mismo proyecto.

- **Fechas:** martes 13, miércoles 14 y jueves 15 de octubre de 2026, 10:00 a 12:00
- **Lugar:** laboratorio del centro de cómputo
- **Instructores:** David Sebastián Montoya Muñoz y Luis Alonso García Mendoza
- **Cupo:** 15 participantes

## Qué necesitas
- Una cuenta de GitHub. Si no tienes, créala antes de la primera sesión en https://github.com/signup.
- Tu celular a la mano, por si tu cuenta pide verificación en dos pasos (2FA).

En las PCs del laboratorio Git ya está instalado. Si quieres practicar en tu computadora, descárgalo de https://git-scm.com/.
