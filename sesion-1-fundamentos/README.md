# Sesión 1: Fundamentos y primer repositorio

**Objetivo:** al terminar la sesión creas un repositorio en tu PC, guardas tu trabajo con commits claros, lo subes a GitHub y sabes corregir un error común: subir una clave por accidente.

## Qué vas a ver
- Para qué sirve el control de versiones y cuál es la diferencia entre Git y GitHub.
- Configurar Git y entrar a tu cuenta de GitHub.
- Guardar cambios: `git init`, `git status`, `git add`, `git commit`.
- Revisar el historial: `git log`, `git diff`, `git show`.
- Dejar archivos fuera del repositorio con `.gitignore`.
- Conectar con GitHub: `git remote`, `git push`, `git pull`.

## Qué necesitas
- Una cuenta de GitHub. Si no tienes, créala antes de la sesión en https://github.com/signup.
- Tu celular a la mano, por si tu cuenta pide verificación en dos pasos (2FA).

En las PCs del laboratorio Git y Git Bash ya están instalados.
